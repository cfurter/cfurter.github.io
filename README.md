# Craig Furter

Personal portfolio site for [cfurter.github.io](https://cfurter.github.io), built as a static page with HTML and CSS.

## Local preview

Open `index.html` in a browser, or serve the repository directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The repository is named `cfurter.github.io`, so GitHub Pages can publish the site directly from the `main` branch.
